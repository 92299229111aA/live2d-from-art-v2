# 素材、拆件与补绘

## 输入与坐标

保存原始 RGBA 和不变的画布大小。记录每个部件的 name、texture、x、y，及全局 width、height；各部件裁剪尺寸可以不同，但偏移必须能恢复同一画布。不要按部件各自居中或单独缩放。

典型 `layout.json`：

```json
{"width":1086,"height":1448,"layers":[{"name":"Body","texture":"parts/Body.png","x":0,"y":500}]}
```

具体位置来自实际图像，不沿用案例数字。检查透明底是否真实 alpha，不把棋盘格当透明。案例的内部 alpha 为252/253，导致叠层接缝；仅在确认内部应为不透明时归一化，保留轮廓的抗锯齿，不对任意素材全部阈值化。

## 分层依据

按动作和遮挡拆分，层数不是质量指标。优先身体/颈部/脸、左右眼、左右眉、鼻、嘴、前后头发；确实需要独立动作时再细拆配饰、衣领和发束。案例23网格不是固定要求。

- 眼睛：保留原画眼部像素；眼皮开口遮罩、闭眼线和下面皮肤分开。该简化方案的眼球不能自由转动；若需要凝视，再拆瞳孔、眼白和高光。
- 嘴：底层皮肤、口腔、上下唇分开；保留闭嘴轮廓，口腔在闭嘴时不能漏出。
- 头发：发根作为稳定锚点，按发束运动方向切分；切口藏在重叠中。不要只依颜色阈值分割，深色眉毛、眼线与头发容易混淆。
- 身体与颈部：转头不能拖动整个衣领；补齐头发移开后露出的领口，避免重复的发丝轮廓残留。

## 遮挡补绘

先列出“动作时会露出”的区域：眼睛闭合处、眉毛位移处、嘴张开处、刘海背后皮肤、颈部和肩部连接。只补需要的范围。

生成式补绘用原图作参考，明确要求保留脸形、皮肤色和光照，只修改遮挡下内容。检查实际结果后再接入。不要让补绘替换整张可见脸，重新生成五官通常会改变角色辨识度。

局部算法修补适合平滑皮肤小孔洞；案例中直接大范围 inpaint 眼区形成污渍，seamlessClone 造成灰色眼眶。遇到这些现象回退，使用审查过的隐藏皮肤层。膨胀蒙版只能扩展到确实被遮挡区域，不能扩大人物外轮廓。

## 静态验收

按实际绘制顺序以默认可见性拼合，在深、浅底色检查透明边缘。和原图并排同尺度对比，尤其检查眼距、眼睑倾角、眉形、鼻位、嘴角、脸宽、头身比及领口。

可统计中性姿态像素差，但应排除有意补绘及隐藏层，注明比较范围。作者侧拼合一致，不代表运行时一致；随后必须在 Core 实际渲染中复查。不要通过把原图盖在模型上制造“还原成功”。
